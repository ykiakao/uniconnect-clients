Funcionalidades do chatbot

  • Assistente flutuante disponivel tanto na tela de login quanto no painel autenticado.
  • Navegacao por arvore de decisoes baseada em chatbotFlow.
  • Mensagem contextual, categoria, titulo, botoes de opcao e passo a passo por no.
  • Historico simples por mapa de pais para o botao Voltar.
  • Reset para o inicio do fluxo.
  • Fechamento por botao e por tecla Escape.
  • Foco gerenciado apos abertura, fechamento e troca de no.
  • Protecao contra HTML injetado por escapeHtml.
  • Sem persistencia remota: o estado atual vive em memoria em state.chatbotNodeId e state.chatbotOpen.

Botoes e controles proprios do chatbot

Como registrar um usuário administrativo registerUser

Categoria: Usuários

Este fluxo já está mapeado no painel, mas a criação real depende do endpoint administrativo.

Passos do fluxo

  1. Entrar no painel com perfil admin, coordenador ou mantenedor.
  2. Clicar em Usuários no menu lateral.
  3. Clicar em Novo registro quando o botão estiver habilitado.
  4. Preencher nome, e-mail institucional, perfil, área e status.
  5. Revisar o tenant exibido no topo para confirmar a instituição correta.
  6. Clicar em Salvar e conferir o novo usuário na tabela.

Botoes/opcoes exibidos

  • Ver cursos -> registerCourse
  • Ver erro de permissão -> accessTrouble

Como registrar um curso registerCourse

Categoria: Cursos

O módulo Cursos está reservado para o CRUD acadêmico do painel.

Passos do fluxo

  1. Entrar no painel administrativo.
  2. Clicar em Cursos no menu lateral.
  3. Clicar em Novo registro quando a API do módulo estiver disponível.
  4. Informar nome do curso, área, coordenador e status.
  5. Salvar o curso.
  6. Abrir Turmas para vincular períodos e professores depois do cadastro.

Botoes/opcoes exibidos

  • Ver turmas -> registerClass
  • Entender módulos -> modules

Como registrar uma turma registerClass

Categoria: Turmas

Turmas organizam alunos por curso, semestre e professor responsável.

Passos do fluxo

  1. Clicar em Turmas no menu lateral.
  2. Clicar em Novo registro quando o endpoint estiver pronto.
  3. Selecionar curso, semestre, período letivo e professor responsável.
  4. Definir capacidade, status e observações administrativas.
  5. Salvar a turma.
  6. Conferir se a turma aparece nos filtros de usuários, notas e relatórios.

Botoes/opcoes exibidos

  • Ver notas -> registerGrade
  • Ver relatórios -> reportsFlow

Como registrar uma atividade acadêmica registerActivity

Categoria: Atividades

Esse fluxo acontece no app do professor, não no painel administrativo atual.

Passos do fluxo

  1. Entrar no app UniConnect com uma conta de professor.
  2. Abrir o dashboard Professor.
  3. Clicar em Criar atividade.
  4. Preencher disciplina, título, descrição, prazo, prioridade e critérios.
  5. Revisar os dados antes de publicar.
  6. Publicar para que alunos vejam em Atividades.

Botoes/opcoes exibidos

  • Registrar nota -> registerGrade
  • Voltar para registros -> register

Como registrar nota de aluno registerGrade

Categoria: Notas

O lançamento de notas é tratado pelo fluxo do professor e deve sincronizar com a API acadêmica.

Passos do fluxo

  1. Entrar no app UniConnect com perfil professor.
  2. Abrir Professor > Notas.
  3. Selecionar turma, disciplina e aluno.
  4. Informar P1, P2, trabalho ou campos definidos pela instituição.
  5. Conferir a média calculada.
  6. Salvar para atualizar a visão Notas do aluno.

Botoes/opcoes exibidos

  • Simulação do aluno -> studentGrades
  • Voltar para registros -> register

Como acessar o painel access

Categoria: Acesso

Use uma credencial administrativa vinculada ao tenant da instituição.

Passos do fluxo

  1. Abrir a URL do painel.
  2. Confirmar a instituição no campo Instituição.
  3. Abrir Configuração avançada apenas se precisar trocar a URL da API.
  4. Informar e-mail institucional e senha.
  5. Marcar Lembrar de mim somente em dispositivo confiável.
  6. Clicar em Entrar.

Botoes/opcoes exibidos

  • Erro de acesso -> accessTrouble
  • Perfis aceitos -> adminRoles

O que conferir quando não entra accessTrouble

Categoria: Acesso bloqueado

A maior parte dos bloqueios vem de API desligada, tenant errado ou perfil sem permissão administrativa.

Passos do fluxo

  1. Verificar se a API uniconnect-api está rodando em http://localhost:3333/api/v1.
  2. Confirmar se a origem http://127.0.0.1:8080 está liberada no CORS da API.
  3. Conferir se o tenant está como universidade-norte ou o slug correto.
  4. Confirmar se o usuário tem perfil admin, coordinator ou owner.
  5. Tentar entrar novamente.
  6. Se a sessão antiga persistir, clicar em Sair e autenticar de novo.

Botoes/opcoes exibidos

  • Perfis aceitos -> adminRoles
  • Como acessar -> access

Quais perfis entram no painel adminRoles

Categoria: Permissões

O painel administrativo é exclusivo para perfis de gestão institucional.

Passos do fluxo

  1. admin pode operar recursos administrativos.
  2. coordinator pode acessar fluxos acadêmicos de coordenação.
  3. owner representa o mantenedor da instituição.
  4. student e teacher não devem acessar o painel web administrativo.

Botoes/opcoes exibidos

  • Registrar usuário -> registerUser
  • Erro de acesso -> accessTrouble

O que fazer em Usuários moduleUsers

Categoria: Usuários

Este módulo centraliza perfis, vínculos institucionais e permissões.

Passos do fluxo

  1. Clicar em Usuários no menu.
  2. Usar a tabela para revisar pessoas recentes enquanto o endpoint não existe.
  3. Quando o CRUD estiver ativo, usar Novo registro para cadastrar usuários.
  4. Validar se cada pessoa pertence ao tenant correto.

Botoes/opcoes exibidos

  • Registrar usuário -> registerUser
  • Perfis aceitos -> adminRoles

Como consultar relatórios reportsFlow

Categoria: Relatórios

Relatórios serão a visão consolidada de desempenho, frequência e atividades.

Passos do fluxo

  1. Clicar em Relatórios no menu lateral.
  2. Selecionar o período letivo quando o filtro estiver disponível.
  3. Filtrar por curso, turma ou disciplina.
  4. Conferir indicadores de notas, frequência e pendências.
  5. Exportar em CSV ou PDF quando a ação estiver habilitada.

Botoes/opcoes exibidos

  • Ver turmas -> registerClass
  • Ver notas -> registerGrade

Como consultar assinatura billingFlow

Categoria: Assinatura

A assinatura usa o contexto do tenant para mostrar plano, status e limites.

Passos do fluxo

  1. Clicar em Assinatura no menu lateral.
  2. Conferir plano atual e status do tenant.
  3. Revisar usuários ativos e limites contratados quando a API expuser esses dados.
  4. Acionar o mantenedor se houver pagamento pendente.

Botoes/opcoes exibidos

  • Erro de acesso -> accessTrouble
  • Entender módulos -> modules

Como o aluno acompanha notas studentGrades

Categoria: Aluno

O aluno vê notas e simula médias no app mobile UniConnect.

Passos do fluxo

  1. Entrar no app com perfil aluno.
  2. Abrir Notas no menu inferior.
  3. Consultar disciplinas, avaliações e média final.
  4. Usar o simulador para estimar a nota necessária.
  5. Se houver divergência, falar com o professor ou coordenação.

Botoes/opcoes exibidos

  • Registrar nota -> registerGrade
  • Voltar ao início -> start

Observacoes tecnicas

  • O chatbot usa uma arvore de decisoes local baseada no objeto chatbotFlow.
  • Cada opcao de fluxo aponta para um destino por data-chatbot-target.
  • Quando um destino invalido e solicitado, o chatbot retorna ao no inicial.
  • O conteudo apresentado no chatbot e escapado por escapeHtml.
